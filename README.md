## 💡 CLEAN WIN 是什么？

**CLEAN WIN** 是一款开源的消息管理软件。它通过捕获系统通知内容及其生成路径，对碎片化的消息进行聚合整理与分析。

* **强提醒设备增强**：原为智能眼镜、智能手表、智能颈环等第三方硬件设计。配合设备的“消息隔离”功能，仅保留本应用的关键提醒，实现核心消息的强区分。
* **日常消息的效率神器**：无硬件亦可独立使用。支持**通知备份、消息防撤回、路径追溯与AI任务总结**，有效解决“消息多而杂、看过就忘、跳转后失联”的痛点。

---

## 🛠️ 功能详解

软件由四个面板组成：

### 1. 主页 (Dashboard)
* **管理开关**：一键启停消息抓取。开启后自动激活后台免杀常驻，确保通知不漏接。
* **任务送达按键**：集中展示“任务完成后送达”的暂存消息，并按时间线呈现 AI 智能分析生成的任务清单。

### 2. 规则页 (Rules)
支持自由定制过滤与送达逻辑：
* **匹配模式**：
    * `消息人名`：按联系人或群组名称精准捕获。
    * `关键字`：包含指定关键词的消息触发捕获。
    * `软件特权`：应用白名单，直接放行指定软件的所有通知。
* **送达时效**：
    * `立即送达`：捕获后即刻弹出本应用通知。
    * `任务结束送达`：暂存，待点击主页“任务结束”时集中列表弹出。
    * `定时送达`：自定义特定时间点集中轰炸。
* **通知**：如果作为日常工具可以点击右上角图表关闭


### 3. 全揽页 (Archive)
* **全量存档**：完整记录所有通知与跳转路径。支持通知留痕，无惧撤回与误删。

### 4. 分析页 (AI Analytics)
* **AI 任务提取**：基于 **DeepSeek-V4-Flash** 模型，自动提取规则捕获消息中的“待办任务”与“时间节点”。
* **智能排序**：自动按截止时间倒序排列；未知时间的模糊任务自动折叠置顶，方便集中处理。
* *注：需自备 DeepSeek 官方 API Key（官方计费约 2 元 / 万条消息）。*
